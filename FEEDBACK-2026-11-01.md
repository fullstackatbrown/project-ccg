# November 1 feedback preview

Branch: `feedback/2026-11-01`, based on the published redesign. No production deployment, Vercel update, or Contentful mutation was performed for this preview.

Run locally with `npm run dev -- --host 127.0.0.1 --port 4322`. Development reads the staged spreadsheet portfolio in `src/data/portfolioReview.json` while the rest of the site continues reading published Contentful content. For a static review build, use `PORTFOLIO_REVIEW=true npm run build`.

## Applied feedback

- The same eight yellow-highlighted projects appear on the homepage and Clients page: Adobe, SoundCloud, Warby Parker, CAVA, GitHub, UNDP, Uber, Grammarly.
- Shared cards show the supplied short description on hover or keyboard focus. Clicking/tapping opens native dialog details with client name, semester and long description. Escape, close, backdrop dismissal and focus restoration are supported.
- The homepage keeps its introduction and Explore Our Client Work link. Logos open the selected engagement directly rather than redirecting to the default Uber panel.
- Clients has one featured grid followed by 29 remaining projects grouped by semester, newest first. Search and semester filtering keep the complete 37-project portfolio navigable. The former redundant grid / pinned selector combination is replaced. Services, values, process, report and the rest of the website are preserved.
- Whole Foods uses a green vector mark and The Trevor Project uses its orange official vector. Other named clients have logo artwork; anonymized projects retain their supplied names rather than invented identities.
- Shopify and Trevor Project short descriptions were swapped in the sheet. The user confirmed correcting them by company name.
- The five Fall 2026 projects have no long descriptions. Their detail views use the supplied short description, as confirmed by the user. No project outcomes were invented.
